# Subsea Cable Disturbance Assessment

A reproducible research prototype for uncertainty-aware multimodal evidence fusion under adversarial uncertainty. The current implementation is intentionally interpretable and separates physical detection, association, attribution, uncertainty, and decision.

## Research integrity

Synthetic outputs are experiment outputs, not scientific claims. No accuracy, F1, AER, FHER, latency, confidence interval, or causal result is included unless generated by an executed experiment. Unsupported capabilities are marked `NOT EXECUTED` or remain explicit adapters.

## Current architecture

- `src/subsea/features.py`: MPU6050 acceleration magnitude and spectral features.
- `src/subsea/health.py`: availability, freshness, constant-value, and sampling health.
- `src/subsea/association.py`: configurable spatial, temporal, and behaviour confidence.
- `src/subsea/fusion.py`: transparent health/availability-weighted evidence fusion and competing hypotheses.
- `src/subsea/pipeline.py`: auditable end-to-end decision pipeline.
- `src/subsea/simulation.py`: deterministic synthetic scenarios.
- `src/subsea/adversarial.py`: vessel-side spoofing, suppression, and timestamp transforms.
- `src/subsea/acquisition.py`: validated ESP32/MPU6050 packet contract.
- `src/subsea/experiments.py`: non-overwriting seeded trial manifests with attack cohorts.
- `src/subsea/metrics.py`: explicit AER and FHER cohort metrics.
- `src/subsea/real_data.py`: read-only CSV/JSON/HDF5 loading with timestamp normalization and source hashes.
- `dashboard/app.py`: Streamlit research view.

## Install and test

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
```

## Run a simulation

```bash
python -m subsea.cli --scenario S04 --seed 42 --output results/s04.json
PYTHONPATH=src python scripts/run_adversarial.py --scenario S04 --attack ais_spoofing --trials 100 --output results/adversarial-s04
PYTHONPATH=src python scripts/run_baselines.py --scenario S01 --scenario S04 --trials 100 --output results/baselines-s01-s04
PYTHONPATH=src python scripts/generate_paper_results.py --manifest results/baselines-s01-s04/method_comparison.json --output results/paper-s01-s04
python -m streamlit run dashboard/app.py
```

The CLI emits intermediate features, health, fusion, hypotheses, uncertainty, decision, counter-evidence, and missing corroboration. Use a new output directory for each experiment; raw data is never overwritten by the experiment runner.

Adversarial trials record `true_h1` and `benign` cohort membership explicitly. Each manifest computes AER and FHER when its denominator cohort exists; otherwise that metric is recorded as `NOT EXECUTED` with a reason. AER is the fraction of true adversarial H1 trials decided as `T0`; FHER is the fraction of benign/non-vessel trials decided as `T2` or `T3`. Empty cohorts are rejected, and these synthetic metrics are not claims about operational resilience. Manifest timestamps are provenance metadata; seeds and records are the deterministic experiment content.

## Configuration

The initial configuration is in `config/system.yaml`. Thresholds and weights are intentionally visible and should be justified by calibration experiments before being used for claims.

## Hardware and real data status

`Mpu6050Packet` validates the expected ESP32 payload and converts it into the common observation model. MQTT, HTTP, serial transport, DAS/HDF5 loading, and hardware-in-the-loop timing are not yet executed in this prototype. The Marlinks-NS distance labels, when integrated, must be treated as association/localization evidence rather than causal attribution ground truth.

## Limitations

The simulator is not an operational ocean model. MPU6050 is a laboratory inertial/vibration sensor, not operational DAS. The adversarial model currently manipulates vessel-side observations while treating cable-side sensing as trusted. Real deployment requires underwater-qualified sensing, synchronization, communications, calibration, and validation. Decision labels are configurable research states, not safety authorization.
